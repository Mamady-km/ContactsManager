# Exercice 1 - Gestionnaire de Contacts

## Description
Ce projet Java permet de gérer une liste de contacts.

L'application permet :
- d'ajouter des contacts
- de rechercher un contact par son nom
- d'afficher son numéro de téléphone

Le projet a été réalisé avec Java dans IntelliJ IDEA.

---

# Structure du projet

Le projet contient 3 classes :

## 1. Contact.java
Cette classe représente un contact.

Elle contient :
- le nom du contact
- le numéro de téléphone
