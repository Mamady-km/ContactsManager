# Exercice 1 - Gestionnaire de Contacts

## Description
Ce projet Java permet de gérer une liste de contacts.

L'utilisateur peut :
- ajouter des contacts
- rechercher un contact par son nom
- afficher son numéro de téléphone

---

## Classes utilisées

### Contact.java
Cette classe représente un contact.

Elle contient :
- le nom
- le numéro de téléphone

---

### ContactsManager.java
Cette classe permet :
- d'ajouter un contact
- de rechercher un contact

Méthodes utilisées :
- addContact()
- searchContact()

---

### Main.java
Cette classe contient la méthode main.

Elle permet :
- de créer les contacts
- d'ajouter les contacts
- de rechercher un contact
- d'afficher les informations trouvées

---

## Fonctionnement du programme

1. Création du gestionnaire de contacts
2. Création de 5 contacts
3. Ajout des contacts dans le tableau
4. Recherche du contact nommé "Balo"
5. Affichage du numéro trouvé

---

## Exemple d'affichage

=== Gestionnaire de Contacts ===

Recherche du contact 'Balo'...

✔ Contact trouvé !
Nom : Balo
Téléphone : 05060708
